## [1.0.2] - 2025-04-23

- Increased limits for pitch values, starting size HP value, and size limits (you can now set lower limits above 1.0 and upper limits below that)
- Your size change no longer animates on entering a room (you will start at the right size immediately)
- Portrait now starts grows down once you get too big. It also grows dramatically faster. Like this:![20250423000629_1](https://github.com/user-attachments/assets/71c7c7cb-0b84-48c0-8286-0170e3e5d821)


- Special thanks to <https://github.com/slacksystem/> Vee and Kat for the following changes:
- Fixed Circe's boons having a flipped effect if you were set to shrink instead of grow.
